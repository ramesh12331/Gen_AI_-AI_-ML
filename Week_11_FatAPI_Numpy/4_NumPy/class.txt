"""
Python Lists:

1. Lists can grow and shrink dynamically.
2. Lists can store different data types.
3. Lists do not directly support element-wise arithmetic.
4. Multidimensional data is more difficult to manage.
5. Numerical operations may be slower for large data.

NumPy Arrays:

1. NumPy arrays generally have a fixed size.
2. NumPy arrays generally store one common data type.
3. NumPy supports element-wise operations.
4. NumPy handles multidimensional data easily.
5. NumPy is faster for large numerical calculations.
"""

flatten() creates a copy.

Changing the flattened array does not affect
the original array.
"""


# ============================================================
# 26. ravel()
# ============================================================

arr = np.array([
    [2, 3, 4],
    [5, 6, 7]
])

ravelled_array = arr.ravel()

print(ravelled_array)

print("Modified Ravelled Array:")
print(ravelled_array)

print("Original Array:")
print(arr)

"""
OUTPUT:

26. Ravelled Array:
[2 3 4 5 6 7]
Modified Ravelled Array:
[ 2  3 40  5  6  7]
Original Array:
[[ 2  3 40]
 [ 5  6  7]]

Explanation:

ravel() usually returns a view.

Changing the ravelled array may affect
the original array.
"""


# ============================================================
# 27. DIFFERENCE BETWEEN flatten() AND ravel()
# ============================================================

"""
flatten():

1. Creates a copy.
2. Original array is not affected.
3. Uses additional memory.

ravel():

1. Usually creates a view.
2. Original array may be affected.
3. Uses less memory when a view is possible.
"""

# 44. PERFORMANCE COMPARISON
# ============================================================

"""
The original value 100,000,000 requires a lot of memory.

So we use 10,000,000 for practice.
"""

n = 10_000_000


# ------------------------------------------------------------
# Python List Performance
# ------------------------------------------------------------

numbers = range(n)

start = time.time()

list_result = [i ** 2 for i in numbers]

end = time.time()

time_taken_list = end - start

print("\n44. Time Taken by Python List:")
print(time_taken_list, "seconds")


# ------------------------------------------------------------
# NumPy Array Performance
# ------------------------------------------------------------

arr = np.arange(n)

start = time.time()

numpy_result = arr ** 2

end = time.time()

time_taken_array = end - start

print("Time Taken by NumPy Array:")
print(time_taken_array, "seconds")


# ------------------------------------------------------------
# Performance Comparison
# ------------------------------------------------------------

if time_taken_array < time_taken_list:
    print("NumPy was faster in this execution.")
else:
    print("Python list was faster in this execution.")

"""
EXAMPLE OUTPUT:

44. Time Taken by Python List:
1.85 seconds

Time Taken by NumPy Array:
0.08 seconds

NumPy was faster in this execution.

Note:

Execution time changes depending on your computer.
"""
