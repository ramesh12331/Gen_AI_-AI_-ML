FASTAPI INSTALLATION - DEFINITION & PURPOSE
============================================================


1. FASTAPI
============================================================

Installation:

pip install fastapi


Definition:
FastAPI is a modern Python web framework used to build
APIs and web applications quickly and easily.


Purpose:
> To create REST APIs.
> To create GET, POST, PUT and DELETE endpoints.
> To receive and return data.
> To build backend applications.
> Automatic API documentation.


Example:

from fastapi import FastAPI

app = FastAPI()


============================================================
2. UVICORN
============================================================

Installation:

pip install uvicorn


Definition:
Uvicorn is an ASGI web server used to run FastAPI
applications.


Purpose:
> To start/run the FastAPI application.
> To handle HTTP requests.
> To communicate between the client and FastAPI.
> To provide a development server.


Example:

python -m uvicorn day1:app --reload


Meaning:

day1
    -> Python file name

app
    -> FastAPI object

--reload
    -> Automatically restart the server when code changes.


============================================================
3. PYDANTIC
============================================================

Installation:

pip install pydantic


Definition:
Pydantic is a Python library used for data validation
and data parsing.


Purpose:
> To validate input data.
> To check data types.
> To convert data into the required type.
> To create structured data models.
> FastAPI uses Pydantic for request validation.


Example:

from pydantic import BaseModel


class Customer(BaseModel):

    name: str
    age: int
    city: str


Here:

name: str
    -> name must be a string

age: int
    -> age must be an integer

city: str
    -> city must be a string

4. JSON
============================================================

Python already provides JSON support.

No installation required.

import json


Definition:
JSON (JavaScript Object Notation) is a lightweight format
used to store and exchange data.


Purpose:
> To store data.
> To exchange data between frontend and backend.
> To store API data.
> Easy for humans and computers to read.


Example data.json:

[
    {
        "customer_name": "Ramesh",
        "age": 25,
        "city": "Hyderabad"
    }
]


Read JSON:

with open('data.json', 'r') as f:

from fastapi import FastAPI
import json


app = FastAPI()


# ----------------------------------------------------------
# Load JSON Data
# ----------------------------------------------------------

class GetData:

    def get_data(self):

        with open('data.json', 'r') as f:
            data = json.load(f)

        return data


# ----------------------------------------------------------
# Home Endpoint
# ----------------------------------------------------------

@app.get('/')
def home():

    return {
        'message': 'Welcome to my FastAPI application'
    }


# ----------------------------------------------------------
# About Endpoint
# ----------------------------------------------------------

@app.get('/about')
def about():

    return {
        'message': 'This is About page'
    }


# ----------------------------------------------------------
# Get All Customers
# ----------------------------------------------------------

@app.get('/customers')
def get_customers():

    data = GetData()

    customers = data.get_data()

    return customers


# ----------------------------------------------------------
# Get All Cities
# ----------------------------------------------------------

@app.get('/cities')
def get_cities():

    data = GetData()

    customers = data.get_data()

    return [customer['city'] for customer in customers]


# ----------------------------------------------------------
# Search Customer By City
# ----------------------------------------------------------

@app.get('/city')
def city_info(city: str):

    data = GetData()

    customers = data.get_data()

    result = []

    for customer in customers:

        if customer['city'].lower() == city.lower():
            result.append(customer)

    if result:
        return result

    return {
        'message': 'No customers found in this city'
    }


# ----------------------------------------------------------
# Customers By Category
# ----------------------------------------------------------

@app.get('/category')
def category_info(category: str):

    data = GetData()

    customers = data.get_data()

    result = []

    for customer in customers:

        if customer['category'].lower() == category.lower():
            result.append(customer)

    if result:
        return result

    return {
        'message': 'No customers found in this category'
    }


# ----------------------------------------------------------
# Customers Above Given Age
# ----------------------------------------------------------

@app.get('/major')
def major_cust(age: int):

    data = GetData()

    customers = data.get_data()

    result = []

    for customer in customers:

        if customer['age'] >= age:
            result.append(customer)

    if result:
        return result

    return {
        'message': 'No customers found'
    }


# ----------------------------------------------------------
# Products Below Given Price
# ----------------------------------------------------------

@app.get('/products/price')
def products_below_price(price: float):

    data = GetData()

    customers = data.get_data()

    result = []

    for customer in customers:

        if customer['price'] < price:
            result.append(customer)

    if result:
        return result

    return {
        'message': 'No products found below given price'
    }


# ----------------------------------------------------------
# Calculate Total Sales
# ----------------------------------------------------------

@app.get('/sales/total')
def total_sales():

    data = GetData()

    customers = data.get_data()

    total = 0

    for customer in customers:

        total += customer['price']

    return {
        'total_sales': total
    }

with open()

customer['age']
    -> Gets age value.


customer['price']
    -> Gets price value.

    -> Adds customer to result list.

    -> Sends result as API response.
