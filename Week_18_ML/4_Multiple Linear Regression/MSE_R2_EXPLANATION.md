# 📊 Mean Squared Error (MSE) & R² Score

## 📌 1. Introduction

In Machine Learning, after training a model, we need to evaluate how well it predicts the output.

For example:

Suppose we build a Machine Learning model to predict students' examination marks based on their study hours.

| Study Hours | Actual Marks | Predicted Marks |
|---:|---:|---:|
| 1 | 25 | 27 |
| 2 | 30 | 32 |
| 3 | 45 | 42 |
| 4 | 50 | 53 |
| 5 | 60 | 58 |

Here:

- **Actual Values (`y_test`)**: Real values from the dataset.
- **Predicted Values (`y_pred`)**: Values predicted by our Machine Learning model.

We need evaluation metrics to understand the difference between actual and predicted values.

Two important evaluation metrics are:

1. Mean Squared Error (MSE)
2. R² Score (Coefficient of Determination)

---

## 📌 2. What is Mean Squared Error (MSE)?

Mean Squared Error is a regression evaluation metric.

It calculates the average of the squared differences between actual values and predicted values.

### 🎯 Why do we use MSE?

MSE helps us understand how much prediction error our model produces.

- Lower MSE indicates smaller prediction errors.
- Higher MSE indicates larger prediction errors.
- MSE = 0 indicates perfect predictions.

### 🧮 Mathematical Formula

$$
MSE = \frac{1}{n}\sum_{i=1}^{n}(y_i-\hat{y}_i)^2
$$

Where:

- `n` = Total number of observations.
- `yᵢ` = Actual value.
- `ŷᵢ` = Predicted value.
- `Σ` = Summation.
- `(yᵢ - ŷᵢ)²` = Squared prediction error.

### 💡 Example

Consider the following values:

```python
Actual Values    = [40, 50, 60, 70, 80]

Predicted Values = [42, 48, 65, 68, 75]
```

**Step 1: Calculate Errors**

| Actual | Predicted | Error |
|---:|---:|---:|
| 40 | 42 | -2 |
| 50 | 48 | 2 |
| 60 | 65 | -5 |
| 70 | 68 | 2 |
| 80 | 75 | 5 |

**Step 2: Square the Errors**

| Actual | Predicted | Error | Squared Error |
|---:|---:|---:|---:|
| 40 | 42 | -2 | 4 |
| 50 | 48 | 2 | 4 |
| 60 | 65 | -5 | 25 |
| 70 | 68 | 2 | 4 |
| 80 | 75 | 5 | 25 |

**Step 3: Calculate Average**

$$
MSE = \frac{4+4+25+4+25}{5}
$$

$$
MSE = \frac{62}{5}
$$

$$
\boxed{MSE = 12.4}
$$

**Result: MSE = 12.4**

This means the average squared prediction error is 12.4.

> Important: MSE is measured in squared target units. If the target is marks, MSE is measured in marks². It does not mean the model is wrong by exactly 12.4 marks.

## 📌 3. What is R² Score?

R² Score is also called the Coefficient of Determination.

It measures how much of the variation in the target variable is explained by the regression model.

### 🎯 Why do we use R² Score?

R² helps us understand how well our model explains the actual target values compared with simply predicting the mean of the target values.

For example:

If R² = 0.92, the model explains approximately 92% of the variation in the target variable.

### 🧮 Mathematical Formula

$$
R^2 = 1 - \frac{SS_{res}}{SS_{tot}}
$$

Where:

**1. Residual Sum of Squares (SSres)**

$$
SS_{res} = \sum (y_i-\hat{y}_i)^2
$$

It measures the squared prediction errors.

**2. Total Sum of Squares (SStot)**

$$
SS_{tot} = \sum (y_i-\bar{y})^2
$$

It measures the total variation of actual values around their mean.

Where:

- `yᵢ` = Actual value.
- `ŷᵢ` = Predicted value.
- `ȳ` = Mean of actual values.

### 💡 R² Score Interpretation

| R² Score | Meaning |
|---:|---|
| 1.00 | Perfect prediction |
| 0.98 | Very high explained variation |
| 0.90 | High explained variation |
| 0.80 | Good explained variation |
| 0.50 | 50% of variation explained |
| 0.00 | No improvement over predicting the mean, on the evaluated data |
| Negative | Worse than predicting the mean, on the evaluated data |

**Important Points:**

- R² = 1 → Perfect predictions.
- R² = 0 → Model performs no better than the mean baseline.
- R² < 0 → Model performs worse than the mean baseline.
- R² can be negative, especially on test data.

> Note: These values are general interpretations, not universal quality standards. Model quality also depends on the dataset and business problem.

### Step 2: Import Required Libraries

```python
import numpy as np

from sklearn.metrics import mean_squared_error
from sklearn.metrics import r2_score
```

### Step 3: Create Actual and Predicted Values

```python
# Actual values from the test dataset
y_test = np.array([40, 50, 60, 70, 80])

# Predicted values generated by our model
y_pred = np.array([42, 48, 65, 68, 75])
```

### Step 4: Calculate MSE

```python
# Calculate Mean Squared Error
mse = mean_squared_error(y_test, y_pred)

print("Mean Squared Error:", mse)
```

### Step 5: Calculate R² Score

```python
# Calculate R² Score
r2 = r2_score(y_test, y_pred)

print("R2 Score:", r2)
```

### Step 6: Complete Code

```python
# =====================================================
# MACHINE LEARNING
# MEAN SQUARED ERROR (MSE) AND R² SCORE
# =====================================================

# STEP 1: Import Required Libraries

import numpy as np

from sklearn.metrics import mean_squared_error
from sklearn.metrics import r2_score


# STEP 2: Actual Values

# These are the real values from our test dataset

y_test = np.array([40, 50, 60, 70, 80])


# STEP 3: Predicted Values

# These values are generated by our trained model

y_pred = np.array([42, 48, 65, 68, 75])


# STEP 4: Calculate Mean Squared Error

# MSE measures average squared prediction error

mse = mean_squared_error(y_test, y_pred)


# STEP 5: Calculate R² Score

# R² measures how much target variation
# is explained by our regression model

r2 = r2_score(y_test, y_pred)


# STEP 6: Display Results

print("Actual Values:", y_test)

print("Predicted Values:", y_pred)

print("--------------------------------")

print("Mean Squared Error:", mse)

print("R² Score:", r2)
```

## 📌 5. Difference Between MSE and R² Score

| Feature | MSE | R² Score |
|---|---|---|
| Full Form | Mean Squared Error | Coefficient of Determination |
| Purpose | Measures prediction error | Measures explained variation |
| Best Value | 0 | 1 |
| Perfect Prediction | 0 | 1 |
| Lower Value | Generally better | Not always better |
| Negative Values | No | Yes |
| Units | Squared target units | No units |
| Used For | Regression | Regression |

### Easy Way to Remember

- MSE → How much prediction error does my model produce?
- R² → How much variation does my model explain?

## 📌 7. Important Interview Questions

**Q1. What is Mean Squared Error?**

MSE is a regression evaluation metric that calculates the average squared difference between actual and predicted values.

**Q2. Why do we square the errors in MSE?**

We square the errors to:
- Prevent positive and negative errors from cancelling each other.
- Give larger errors more weight.

**Q3. What is the best MSE value?**

MSE = 0 indicates perfect predictions.

**Q4. What is R² Score?**

R² Score measures how much of the variation in the target variable is explained by a regression model.

**Q5. What is the best R² Score?**

R² = 1 indicates perfect predictions.

**Q6. Can R² Score be negative?**

Yes. A negative R² means the model performs worse than predicting the mean of the actual target values.

**Q7. What is the difference between MSE and R² Score?**

MSE measures prediction error, whereas R² measures explained variation.

**Q8. Can we use MSE and R² together?**

Yes. They provide different information about regression model performance.

**Q9. Does R² = 0.95 mean the model is 95% accurate?**

No. It means the model explains approximately 95% of the variation in the target variable. It is not the same as classification accuracy.

**Q10. Is a lower MSE always better?**

Generally, yes, when comparing models on the same target and evaluation dataset. However, model complexity, generalization, and the cost of errors should also be considered.
